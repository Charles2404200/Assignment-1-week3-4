Design notes. Expansion is per-card and in place — no modal, no navigation, nothing that could confuse the reader about where they are. The same control toggles between Read more and Show less, staying inline at the end of the text so focus never jumps. Set align-items: start on the grid (Tailwind items-start) for the expandable row so only the expanded card grows; keep items-stretch if the team prefers whole-row equal height. The control keeps keyboard focus after activation and aria-expanded flips to true, so a screen reader announces the change without moving the user.
