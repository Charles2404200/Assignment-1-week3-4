Design notes. Focus ring = outline 2px solid brand-600 (#4f46e5) with 2px offset, applied via focus-visible: so it appears for keyboard users without adding a ring on every mouse click. The password input here is shown in its focused state. Tab order follows DOM order — no tabindex values above 0 anywhere in the design. The brand panel is decorative and contains no focusable elements, so keyboard users never tab through it.
