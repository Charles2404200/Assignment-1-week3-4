Design notes. Two distinct error levels. Form-level (shown here, above the form): the authentication failure returned by Firebase — the alert reuses the existing message string "Invalid email or password" and the existing "Please verify your email before signing in." string, restyled as an inline alert with role="alert". Field-level: the existing Zod messages from loginSchema, unchanged, rendered under their input. Errors never rely on colour alone — each carries an icon and a text label, and invalid inputs get aria-invalid="true" plus a red border (a shape/contrast change, not just hue). Field-level example shown on the password field only, to keep the frame readable.
