Design notes. Sample names and blurbs are placeholders — real member details are owned by the developer implementing the page. Grid is grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 with items-stretch, so every card in a row shares the tallest card's height. Card order is DOM order; each card is a list item inside a <ul> so screen readers announce "list, 5 items". Roles are limited to the four values in FR-05 and each badge shows the role as text, with colour as decoration only.
