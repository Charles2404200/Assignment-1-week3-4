Design notes. Missing photo (FR-03): the placeholder occupies the identical 4rem circle, so the name, badge and blurb below it sit on exactly the same vertical rhythm as a card with a photo. Long name: line-clamp-2 plus a reserved min-height of two lines means a one-line name and a two-line name produce the same card geometry — short names do not make short cards. overflow-wrap: anywhere handles a single unbroken 80-character token. Long blurb (collapsed): truncated at 250 characters with an ellipsis and an inline Read more button, which is a real <button> — focusable, Enter/Space activated, and carrying aria-expanded + aria-controls.
